# 💳 System Pagos API

API RESTful para la gestión y procesamiento de pagos desarrollada con **Spring Boot**, **PostgreSQL** y empaquetada con **Docker**.

---

## 🛠️ Tecnologías utilizadas

* **Java 21**
* **Spring Boot 3** (Spring Data JPA, Spring Web)
* **PostgreSQL 16**
* **Docker & Docker Compose**
* **Maven**

---


### Prerrequisitos
* Tener instalado **Docker Desktop** y **Git**.
